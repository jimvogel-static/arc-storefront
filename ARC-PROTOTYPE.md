# Bounteous ARC Storefront (prototype)

A look-and-feel prototype built on Adobe's **Commerce boilerplate for Edge Delivery Services** (`hlxsites/aem-boilerplate-commerce`), skinned with the Bounteous 2026 design system. The real Commerce drop-ins (PLP, PDP, mini-cart, cart, checkout, auth, account, order) all render. Their GraphQL calls are answered **in the browser** by a mock layer, so no Commerce backend is involved.

## What's in this folder

| Path | What it is |
|---|---|
| `repo-overlay/` | Files to copy on top of a fresh repo created from the boilerplate template |
| `repo-overlay/scripts/arc-mock/` | The mock: a small GraphQL executor (`gql.js`), the ARC catalog (`catalog.js`), resolvers for Catalog Service and Core operations (`resolvers.js`), and the fetch interceptor (`mock.js`) |
| `repo-overlay/styles/arc-theme.css` | Bounteous 2026 tokens mapped onto the drop-in design tokens |
| `repo-overlay/blocks/arc-hero`, `arc-tiles` | Two small home-page blocks |
| `repo-overlay/images/arc/` | Original SVG product illustrations (generated by `tools/make_product_art.py`) |
| `repo-overlay/config.json` | Storefront config pointing both endpoints at the mock origin |
| `repo-overlay/head.html` | The boilerplate head, with the mock loaded first and the ARC theme and Nunito Sans added |
| `da-content/` | DA.live page source for home, nav, footer, and four category pages |

## How the mock works

1. `head.html` loads `scripts/arc-mock/mock.js` before any drop-in code.
2. `config.json` sets `commerce-core-endpoint` and `commerce-endpoint` to `https://arc-mock.bounteous.invalid/...` (a host that can't resolve).
3. `mock.js` wraps `window.fetch`. Requests to that host are parsed as GraphQL and resolved against `resolvers.js`. The response is shaped to exactly the fields the drop-in asked for, including fragments and aliases.
4. Each visitor's carts, profile, and orders are kept in their own browser `localStorage`. Run `arcMock.reset()` in the console to start fresh before a demo.

## Demo script

- **Any email and password signs in.** The account belongs to "Avery Quinn" and comes with two past orders.
- **Coupons:** `ARC20` takes 20% off and `BOUNTEOUS10` takes 10% off. Any other code shows the "invalid coupon" error.
- **Shipping:** Standard is $5 (free over $100) and Express is $15. Demo sales tax is 8.25%, applied once an address is entered.
- **Payment:** "Pay by invoice" or "Bank transfer". Both are demo methods with no charge.
- **Options:** The Midnight Hoodie and the Gradient Signal Tee have color and size options. Hoodie XS is out of stock, and the laptop sleeve shows an out-of-stock product.

## Setup (one time)

1. Create the repo from the template: **Use this template → Create a new repository** on `hlxsites/aem-boilerplate-commerce`.
2. Install AEM Code Sync on that repo: https://github.com/apps/aem-code-sync
3. Copy `repo-overlay/*` over the repo root and push to `main`.
4. Run Site Creator in DA.live (**Use existing repository**) to seed the starter commerce pages (cart, checkout, customer, order, and product template).
5. Replace `index`, `nav`, and `footer` with the files in `da-content/`, add the four category pages, then preview and publish.
6. Turn on site authentication through the Configuration Service (`access.site.allow: ["*@bounteous.com"]`).
